The differential oracle of test/overlap.c --dump, and its comparison half.

The same corpus, the same trees, the same order; only the printing of the doubles differs, because C’s %.17g and Rust’s shortest round-trip formatting spell the same value differently. --check therefore parses a dump instead of diffing it, which compares the values themselves — and since %.17g round-trips, the comparison is exact, not approximate.

make -C ../test overlap && ../test/overlap --dump 10 > golden.txt   # the C coordinates
cargo run --release --bin dump -- --check golden.txt 10             # the Rust ones
