A tree of exactly n nodes in breadth-first order; tg_bench_tree.

The random trees of build are the wrong shape for a benchmark: their size is an outcome rather than an input. Here every node but the root is handed to a parent in breadth-first order, 1 + rand(maxkids) at a time, so the size is exact and the shape is still irregular.

The draws are the same as the C tg_bench_tree, in the same order, so both build the very same tree from a given seed – which is what makes the two benchmarks comparable.
