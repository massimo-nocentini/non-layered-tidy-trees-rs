A chain of depth nodes, each the only child of the previous one; tg_chain.

Built iteratively, where the C recurses: a chain is exactly the shape that would run the builder out of stack long before the flat layout it is meant to exercise runs out of anything. The nodes come out in the same order, labelled from idx.
