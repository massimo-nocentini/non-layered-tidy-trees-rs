Module treegen 

Source
Expand description

Test support: a deterministic generator of random trees and a few geometric predicates.

This is the port of test/treegen.h. It lives in the library rather than beside the tests because the differential oracle (src/bin/dump.rs) needs the very same corpus, and because the generator has to stay bit-compatible with the C one: the trees are identified by their seed alone, so the sequence of draws must not drift.
